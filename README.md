# ZionLife Bible Quiz App 📖✨

**Created & Developed by:** Evang. Thankgod Okoduwa

ZionLife Bible Quiz is an interactive, mobile-responsive single-file web application designed to test and strengthen scripture knowledge across two comprehensive stages featuring 200 questions in total.

---

## 🚀 Live Demo
Play the quiz online: [https://STARSAINT7.github.io/zionlifebiblequiz/](https://STARSAINT7.github.io/zionlifebiblequiz/)

---

## 🔥 Key Features
* **Two-Stage Progression System:**
  * **Stage 1 (Fundamental Mastery):** 100 foundational Bible questions with a 30-minute timer.
  * **Stage 2 (Advanced Mastery):** 100 deep-dive scripture questions with a 30-minute timer.
* **Smart Quiz Engine:** Built-in array shuffling logic that randomizes both questions and answer positions on every attempt.
* **Instant Feedback & Scoring:** Real-time answer highlights, progress tracking, and final score summary upon completion.
* **Modern UI Design:** Single-page application built with CSS glassmorphism effects, dynamic gradient background, and responsive layouts.
* **Zero External Dependencies:** Built with pure HTML5, CSS3, and Vanilla JavaScript—runs directly in any modern browser.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Hosting:** GitHub Pages
